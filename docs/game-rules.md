# Правила игры

- Начинай с `supabase/functions/game-actions/rules.js` для боевых действий, покупок, наград и изменения сохранения. `src/modules/game/secure-game.js` связывает действия и серверные снимки с интерфейсом.
- Общие параметры и формулы сверяй в обоих `constants.js`. Текущие числа бери из кода. При правке награды сравни значения на ранних, средних и высоких уровнях, а также отдельно для обычной луны и босса.
- Различай текущий уровень, рекорд забега и рекорд аккаунта. Для открытия лун проверяй рекорд забега и покупку предыдущей луны. Для престижа проверяй повторное прохождение рубежа, вознесение и следующий забег.
- При правке Клона проверь число отражений, разные оригиналы и отображение оригинальных и зеркальных эффектов. При правке Фортуны сверь серверные выплаты, подписи секторов и момент обновления баланса после анимации.
- Лунная пыль копится за несколько полных циклов. Проверь дробный прирост на первом уровне, переход через 100%, массовый сбор и сохранение остатка. Изменение темпа начисления само по себе не требует пересчёта накоплений.

См. [тестирование](testing.md) и [релиз](release.md).
