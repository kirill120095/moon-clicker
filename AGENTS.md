# Moon Clicker

Браузерный кликер на Vanilla JS и CSS, без сборки. Репозиторий `kirill120095/moon-clicker`, ветка `main` публикуется на [GitHub Pages](https://kirill120095.github.io/moon-clicker/). Серверные действия выполняются в Supabase, проект `zllnsmztaakdwjpnijsk`.

## С чего начать

1. Проверь рабочие изменения и базовый коммит. Перед публикацией сверься с `origin/main`.
2. Открой профильную инструкцию по таблице. Если доступен локальный `LEARNING.md`, найди записи по теме и сверь их с кодом. Журнал хранит историю решений.
3. Найди вход в нужный сценарий через `rg`. Читай фрагменты больших файлов и ограничивай дифф задачей.

| Задача | Инструкция |
| --- | --- |
| Баланс, прогресс, луны, престиж, пыль, Фортуна | [Правила игры](docs/game-rules.md) |
| Вход, сохранения, сеть, RLS, админские действия | [Supabase и сохранения](docs/supabase-operations.md) |
| Панели, анимации, звук, слабые устройства | [Интерфейс и производительность](docs/ui-performance.md) |
| Проверка правки | [Тестирование](docs/testing.md) |
| Публикация, резервные версии, откат | [Релиз](docs/release.md) |

## Общие правила

- Сохраняй совместимость со старыми сохранениями и существующими вызовами, если задача не требует миграции.
- Баланс и общие формулы держи в коде. При изменении общих правил сверь `src/core/constants.js` и `supabase/functions/game-actions/constants.js`.
- Береги пользовательские правки. Для удаления данных и разрушительных операций Git нужно явное разрешение. Секреты, токены и содержимое `.env` не выводи и не коммить.
- Сопоставь результат с запросом и укажи, что реально проверил. Для значимой задачи добавь в локальный журнал только новый подтверждённый урок, если он пригодится повторно.
- Меняй этот файл по прямому запросу пользователя.
